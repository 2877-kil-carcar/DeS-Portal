## 開き方

統合版は `index.html` をHTTP(S)配信して開いてください。`file://` では熊罠配置のES Modules等が動作しません。

Node.jsは閲覧には不要です。Pythonがある場合のローカル確認例：本フォルダで `python -m http.server 8791 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8791/?preview=1` を開きます。このURLは同じPC専用です。

- `?preview=1`：ギャラリーはローカルのサンプル表示、熊罠は保存しない試し置き、ゲームは接続・対戦操作無効。Firebase SDKや外部フォント等の取得は発生しますが、アプリ側の認証・DB操作を実行しないようにしています。
- 通常URL：ギャラリー・熊罠・ゲームは元アプリと同じFirebase等へ接続します。試験中はプレビューモードを推奨します。
- `standalone.html`：乗り手選定・図鑑・戦闘ターン・出典だけの1ファイル版。動画・共有DB・ゲームを含む統合版全体の単一ファイル化ではありません。iPhoneのファイルプレビューではなく、HTTP(S)上のSafariで確認してください。

## Cloudflare交換中継（v3.8）

ブラウザからCentury Games公式交換APIへの直接POSTは送信元検査でHTTP 403になるため、固定宛先だけを許可するCloudflare Workerを追加しました。ポータルは `des-giftcode-proxy.shunya3624716.workers.dev` に署名済みフォームを送り、Workerが公式サイトの送信元情報を付けて公式APIへ転送します。Workerはポータル本番URLと指定ローカル開発URLだけをCORSで許可し、入力形式を検査します。中継コードは `cloudflare-worker/worker.js`、オフライン検査は `node tools/test-redeem-worker.mjs` です。

APIキーや利用者ログインは不要です。プレイヤーID、王国、交換コード、時刻、署名は交換処理のためCloudflare WorkerとCentury Gamesへ送信されます。Workerコードでは保存・ログ出力を行いませんが、Cloudflareおよび送信先側の基盤ログまでは本リポジトリから保証できません。

## SvS・申請フォームの追加（v3.3）

スマホは「一覧」、PCは左メニューから開きます。直接確認する場合は `/?preview=1#svs` または `/?preview=1#forms`。この2画面のプレビューはFirebase SDK・認証・DB・通知メールを呼ばず、サンプル／メモリ上の変更だけで動作します。SvSの共有データ編集はプレビューで禁止していますが、振り分けとカウントアップは試せます。

通常モードは元と同じFirebaseプロジェクト・コレクションへ接続します。元の管理機能・計算・コピー・リンク編集・メモを維持し、画面を明るい配色、横スクロール表、44px以上の操作ボタン、スマホ用16px入力へ調整しました。1ファイル版にはこの2機能を含めません。

- SvS：初期グループ未定義、未定義の装飾関数、引用符を含むグループ名の操作エラー、負の兵種比率、参加OFF時の部分保存、接続失敗時の無案内を修正。管理リスナーの重複登録を解消。古いログの自動削除は匿名の起動時でなく、従来の特権管理者ログイン後だけ実行します。
- 申請フォーム：メモをHTMLとして解釈しない描画、HTTP(S) URL検査、編集した1項目だけの共有保存、失敗時の入力保持、端末保存不可時の案内を追加。
- 元のメモキーは維持しています。ただし端末メモはブラウザのオリジン単位です。旧サイトとURLのホスト・ポートが異なる場合、旧メモは自動移行されません。必要なメモは旧画面からコピーしてください。
- **公開前の要対応**：SvSの元実装にはクライアント内の固定管理者認証、Firestoreへの平文パスワード保存、クライアント側の権限判定が残ります。見た目の操作制限はアクセス制御ではありません。フォームも元の匿名認証を継承しています。Firebase Authenticationとサーバー側ルールの設計・移行は今回未実施です。現状をセキュリティ改修済みとして公開しないでください。

## GitHub Pages

HTML/CSS/JSを配信する構成なのでGitHub Pagesへ配置可能です。[GitHub公式説明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)（2026-10-04確認）。ギフトコードはCloudflare Worker経由で送信するため、利用者PCのPythonは不要です。

公開前に必ず確認：

- Firebaseの認証・許可ドメイン・Firestoreルール。クライアントの「管理者パスワード」やsessionStorageはサーバー側のアクセス制御ではありません。既存の仕組みを継承しており、セキュリティ監査済みではありません。

- 通常モードの編集は元の共有DBへ反映されます。バックエンド接続と書込は今回未試験。配置の削除＋再配置は単一バッチですが、別端末との同時操作の排他制御はありません。
- ギャラリー素材・同盟情報・元ガイドの公開権限。既存の動画・画像を含むZIPです。
- iPhone/Safariの実機確認。ミニゲームは内蔵ブラウザでスマホ相当幅／PC幅を確認済みですが、実機固有のタッチ操作は未実施です。
