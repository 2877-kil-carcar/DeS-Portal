## 開き方

統合版は `index.html` をHTTP(S)配信して開いてください。`file://` では熊罠配置のES Modules等が動作しません。

Node.jsは閲覧には不要です。Pythonがある場合のローカル確認例：本フォルダで `python -m http.server 8791 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8791/?preview=1` を開きます。このURLは同じPC専用です。

- `?preview=1`：ギャラリーはローカルのサンプル表示、熊罠は保存しない試し置き、ゲームは接続・対戦操作無効。Firebase SDKや外部フォント等の取得は発生しますが、アプリ側の認証・DB操作を実行しないようにしています。
- 通常URL：ギャラリー・熊罠・ゲームは元アプリと同じFirebase等へ接続します。試験中はプレビューモードを推奨します。
- `standalone.html`：乗り手選定・図鑑・戦闘ターン・出典だけの1ファイル版。動画・共有DB・ゲームを含む統合版全体の単一ファイル化ではありません。iPhoneのファイルプレビューではなく、HTTP(S)上のSafariで確認してください。

- カメラ：以前は「足元の下の足場までの距離」で高さを決めていたため、穴の上を跳ぶとカメラが落ちていました。キャラの高さだけを追う作りに変え、上下にもドラッグで回せます。
- 重い箱の2人運び：歩いた人が動かし、ほかのつかんでいる人は箱ごと引かれます（同時に歩いたら id が先の人）。箱の場所を知らせるのは動かしている人だけです。以前は、箱の前で仲間が視界に入ると仲間をつかんで固めてしまい、また放した人が自分の端末の置き場所を全員に送って箱が飛んでいました。つかむ相手は箱を先に探します。
- 運んだ箱を斜め向きで置くと、箱にはさまって動けなくなることがありました。置く距離を広げ、めり込んだ箱からは抜け出せるようにしています。
- 検査の自動操縦は、上下する床に「下りてくるのを待って」乗ります（上がっている間に踏み出すと床の下へ落ちる）。止まるときに少し流れるので、縁の手前で止まります。

### ギフトコードメニュー（追加）

「ギフトコード」はスマホ下部メニューから直接開けます。プレイヤー・履歴の正本は専用Firebaseです。追加・王国変更時はCloudflare中継経由で公式交換APIにIDと王国を確認し、実交換も確認ダイアログの後に同じ中継へ送信します。`?preview=1` ではサンプルのみ表示し、Firebase認証・DB・交換APIへの通信を行いません。1ファイル版の対象には含めません。
