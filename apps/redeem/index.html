元の wos_redeem/server.py を利用し、同フォルダの登録プレイヤーと履歴を継続使用します。元ツールと統合版を同時に操作しないでください。

GitHub Pagesや通常の静的サーバーでは交換APIが動きません。この版は同じPCからの利用に限定しています。スマホからの実交換には別途、認証付きサーバーの設計が必要です。
