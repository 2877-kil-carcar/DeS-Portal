共有・起動方法

登録プレイヤーと交換履歴は専用Firebaseで共有されます。リンクを知る利用者は匿名認証で閲覧・追加・変更・削除できます。

実際に交換するときは、統合版フォルダの start_hub.bat を実行してください。Python 3があれば交換可能なローカル画面が自動で開きます。

GitHub Pagesでは共有登録の編集まで可能です。交換処理はPC上のローカルサーバーからのみ実行します。
