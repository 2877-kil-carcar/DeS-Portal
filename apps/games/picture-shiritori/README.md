# 絵しりとり

DeSポータル向けの2〜8人用オンライン絵しりとりです。既存ゲームと同じFirebase Realtime Databaseを使い、データは`pictureShiritori/rooms`配下へ分離しています。

## 主な仕様

- 部屋作成・部屋コード参加
- 描く人 → 次の人が回答 → 回答者が次に描くターン制
- 開始するたびに、接続中の参加者の描画・回答順をシャッフルして部屋全体で共有
- 最初のひらがな1文字をランダムに指定（通常の清音44文字。濁音・半濁音・小文字・を・んを除外）
- 「マージ→じ／じゃ／じゅ／じょ」「やしゅ→ゆ／しゅ」のようなつなぎ方に対応
- スマホのPointer Events対応キャンバス
- ひらがな正規化、先頭文字、末尾の「ん」、使用済み単語の検査
- 回答終了後に単語・絵・結果を履歴表示
- 部屋主による終了、参加者の退出、部屋主の自動引き継ぎ
- 描画は30/60/90/120秒、10〜600秒のカスタム、時間制限なし
- 回答は30/60/90/120秒または10〜600秒で個別設定
- 回答時間切れはゲーム終了となり、その絵を描いた人が敗者
- 通信切断後180秒は再接続待ちとして手番と残り時間を維持
- 通信復旧時に自動復帰。回答や絵の提出は不要で、画面復帰時にも最新状態を確認
- 切断のたびに検知を再登録。古い接続の遅延通知と複数タブの接続を分離
- 通信結果が15秒以内に確認できなければ待機を解除して再試行を案内
- 描きかけの絵・答え・回答入力を同じタブのsessionStorageへ保存し、再読み込み時に復元（保存を許可するブラウザーのみ）
- 自分が描く番は背景を薄い赤、答える番は緑に変更。描く人・答える人と順番を表示
- 部屋内チャット（最新80件）。上部に最新メッセージと未読数を表示し、タップ時のみ履歴・入力欄を開く
- チャットはロビー・ゲーム中・終了後に利用可能。送信処理は描画・回答から独立し、未読状態を同じタブに保存
- 設定変更は次ターンから反映、残り10秒警告、時間切れ自動スキップ

## ローカル検証

```powershell
node .\apps\games\picture-shiritori\validate.cjs
node .\apps\games\picture-shiritori\test-reconnect.cjs
node .\apps\games\picture-shiritori\test-gameplay.cjs
```

`test-reconnect.cjs` は実際のアプリを仮想時刻・模擬Firebase・模擬DOMで実行します。3分境界、連続切断、複数人、タイムアウトと遅延提出、人数上限、描画復元を検証し、本番データには接続しません。

`test-gameplay.cjs` は文字のつなぎ方、開始文字と順番、手番表示、複数人のチャット送信・未読管理・履歴上限・再接続を検証します。

Playwrightが利用可能な環境では `node .\apps\games\picture-shiritori\test-reconnect-browser.cjs` で320px・390px幅のChromeによる画面操作も検証できます。パッケージが通常の検索先にない場合は `WOS_PLAYWRIGHT_MODULE` にPlaywrightの絶対パスを設定してください。テスト用HTTPサーバーは終了時に停止し、Firebaseの通信はすべて模擬応答に置き換えます。

ミニゲーム一覧から起動できます。既存Firebaseの公開ルールを利用し、専用パスへ保存します。
