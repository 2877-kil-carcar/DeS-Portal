# 絵しりとり

DeSポータル向けの2〜8人用オンライン絵しりとりです。既存ゲームと同じFirebase Realtime Databaseを使い、データは`pictureShiritori/rooms`配下へ分離しています。

## 主な仕様

- 部屋作成・部屋コード参加
- 描く人 → 次の人が回答 → 回答者が次に描くターン制
- スマホのPointer Events対応キャンバス
- ひらがな正規化、先頭文字、末尾の「ん」、使用済み単語の検査
- 回答終了後に単語・絵・結果を履歴表示
- 部屋主による終了、参加者の退出、部屋主の自動引き継ぎ
- 描画は30/60/90/120秒、10〜600秒のカスタム、時間制限なし
- 回答は30/60/90/120秒または10〜600秒で個別設定
- 回答時間切れはゲーム終了となり、その絵を描いた人が敗者
- 通信切断後180秒は再接続待ちとして手番と残り時間を維持
- 設定変更は次ターンから反映、残り10秒警告、時間切れ自動スキップ

## ローカル検証

```powershell
node .\apps\games\picture-shiritori\validate.cjs
```

ミニゲーム一覧から起動できます。既存Firebaseの公開ルールを利用し、専用パスへ保存します。
